Add playlist

Point Telly at your channels. The first three keep the playlist in this browser, where it stays. A Telly account keeps it on your own server instead, so every device you sign in on sees the same thing.

Your browser fetches the playlist directly, so the server must allow cross-origin requests. If it refuses, save the file and use the File option — that always works.

The file never leaves this device. Very large playlists may be too big to remember between visits — Telly will tell you if that happens.

Credentials are stored in this browser in plain text so Telly can reconnect, and the password forms part of every stream URL — that is how Xtream Codes works. Use a private device.

This is the option that follows you between devices. The other three keep the playlist in this browser, where it stays — local storage is per device, so a playlist added on a PC is not on the phone. Sign in here and the playlist, the categories and the favourites come from the account instead, the same on every device you sign in on.

Your password is sent once and never stored: this browser keeps a pair of session tokens the server can revoke, and nothing else. The provider's own credentials never leave the server — playback goes through a short-lived signed link it cuts for one channel at a time. The server is telly/server in this repository; run it on a PC or a VPS and point this at it.

These lists are maintained by open-source projects that index publicly available streams — free-to-air broadcasters and free ad-supported services. Telly does not host any of them, and a list can change or go down at any time. Pick one and it loads like any other URL.
